# PROJECT_GOAL.md — AI Career Assistant

## Primary Goal

Build a complete **Python full-stack AI/ML application** while learning professional software development step by step.

This project is simultaneously:

- a hands-on learning environment,
- a full-stack development project,
- an AI/ML learning project,
- a Git/GitHub learning project,
- and a portfolio project.

The goal is **not** to blindly generate an application. The goal is to understand how every major part works.

## Product Vision

The final application should allow a user to:

1. Create an account.
2. Log in securely.
3. Access a personal dashboard.
4. Upload a PDF resume.
5. Have the backend store and parse the resume.
6. Extract useful information such as skills.
7. Match the user to careers/jobs.
8. Identify gaps.
9. Provide AI-assisted career recommendations.
10. Display everything clearly in a frontend dashboard.

## Current Product Direction

Backend foundation has already reached:
- authentication,
- protected routes,
- resume PDF upload,
- PDF text extraction,
- storing extracted resume text.

The frontend now supports authentication, resume upload/text/skills, role overlaps
and temporary skill review checklists. As of 2026-09-17, the user wants to continue
product features; public deployment preparation remains available separately.

## Success Definition

A successful finished project should be:

- functional end to end,
- understandable by the user,
- testable,
- documented,
- version-controlled,
- portfolio-presentable,
- explainable in an interview,
- extendable without major rework.

## Learning Rule

Every important coding step should answer:

- What am I doing?
- Why am I doing it?
- Where does it belong?
- How does it work?
- How do I test it?
- How do I know it worked?
- What did I just learn?
